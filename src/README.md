# Food Ordering System

## Project Overview
The Food Ordering System is a Java-based application that allows users to select food items, add them to a cart, view bills, and confirm orders.

## Features
- Food Menu
- Cart Management
- Add and Remove Items
- Bill Generation
- Order Confirmation

## Technologies Used
- Java
- Visual Studio Code

## Project Structure
- FoodItem.java
- FoodMenu.java
- CartItem.java
- Cart.java
- Bill.java
- OrderConfirmation.java

## Team Project
This project is developed as a Java case study by a team of five students.
